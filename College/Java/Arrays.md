# Array Syntax:

```java
String[] array;
int[] array;

int[] array = {1, 2, 3};

int[] array = new int[4] // creates an array of size 4
```

## Array methods:

```java
array.length //gives length of the array
```

# Multi Dimensional Arrays:

```java
int[][] array = new int[2][3];
// creates a matrix of 2x3
```
