# if, else if, else:

```java
if (condition){

}

else if (condition){

}

else {

}
```

*One line method*:

```java
if (condition) age = 18; // if one line code then no need of curly braces

//works with all else if and else.
```

*Shorthand Notation*:

```java
variable = (condition) ? expressionTrue : expressionFalse;
```
