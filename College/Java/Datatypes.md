- All the datatypes are:
1. String
2. int
3. float
4. char
5. boolean

*Declaration format:* 
```java
type variableName = value;

// or just declaration:
type variablename;

int age = 15;
String name = "John";
```

### All type declaration:

```java
int age = 15;
float floatnum = 5.99f;
char letter = 'D';
boolean bool = true;
String name = "Subham";
```
