## String methods:

```java
String txt = "QWERTYUIOPASDFGHJKLZXCVBNM";

// Length of the string
txt.length();

// upper or lower case
txt.toUpperCase();
txt.toLowerCase();

// find first occurance of a word or character
txt.indexOf("UIO");

// index a string to get character:
txt.charAt(0);

// compare equality of strings
txt1, txt2
txt1.equals(txt2);  // returns true or false

// remove white spacces at the end and start of the string
txt.trim()

// concatenate strings
txt1.concat(txt2) // txt1 + txt2


```
