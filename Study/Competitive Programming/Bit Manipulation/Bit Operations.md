## There are Some operations:

### 1. And Operator:

& - bitwise and operator

```cpp
a&b // bitwise and

// example
22 & 26 // results in 18
```

### 2. Or Operator:

| - bitwise OR operator

```cpp
a|b

//example
22 | 26 // returns 30
```

### 3. Xor Operator:

^ - bitwise XOR operator

```cpp
a ^ b

22 ^ 26 // returns 12
```

### 4. Not Operator:

~ bitwise not operator:

```cpp
~a

x = 29
~x // returns -30
```
