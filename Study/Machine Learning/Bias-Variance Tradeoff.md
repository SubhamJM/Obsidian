### Bias

- Relates to model [[Underfitting]]
- as model complexity increases, the bias ==***reduces***==
- simple model = simple assumptions = high error in actual prediction

### Variance

- relates to model [[Overfitting]]
- as model complexity increases, variance ==***increases***==
- complex model = more sensitive weights = high error in small changes in data

> The main goal is to find a sweet spot between high and low model complexity to get low bias and low variance
