### What is Underfitting?

- a model is ==too simple== to capture the true patterns in data, leading to high bias and poor performance on both training and testing sets.
- majorly happens when there are ==very less parameters== in the model to train on.

![[underfitting_vs_overfitting.png]]

### Fixing Underfitting

1. Increase model complexity
2. Add more features
3. train model for longer
