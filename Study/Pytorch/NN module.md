> *torch.nn* module in pytorch, provides many classes for developers to make NNs easily

### *Common Layers:*

- nn.Linear (fully connected layer)
- nn.Conv2d 
- nn.LSTM

## Activation functions:

- nn.ReLU
- nn.Sigmoid
- nn.Tanh

### Loss Functions:

- nn.CrossEntropyLoss
- nn.MELoss
- nn.NLLLoss

### Container Modules:

- nn.Sequential

### Regularisation and Dropout:

- nn.Dropout
- nn.BatchNorm2d

> Basically all the basic functionality is given so we dont have to write everything from hand as in [[BasicNeuralNetwork (without Pytorch)]]
